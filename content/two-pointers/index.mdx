Два указателя — первый приём, который превращает вложенный цикл в один проход. Идея простая: вместо того чтобы перебирать все пары, мы держим две позиции в данных и на каждом шаге двигаем **одну** из них, доказывая, что отброшенный вариант в ответ попасть не мог.

## Три схемы, которые покрывают почти всё

**Навстречу друг другу.** `left = 0`, `right = n - 1`, сходятся к середине. Работает, когда данные отсортированы и по сумме/сравнению краёв понятно, какой край можно выбросить. Отсюда — пара с заданной суммой, палиндром, квадраты массива.

**В одном направлении, с разной скоростью.** Медленный указатель отмечает, куда писать, быстрый — что читать. Отсюда — удаление дубликатов на месте, перенос нулей в конец, поиск цикла в списке (черепаха и заяц).

**Снаружи внутрь по значению, а не по позиции.** Как в квадратах отсортированного массива: максимум лежит на одном из краёв, и результат заполняется с конца.

## Почему это вообще законно

Ключевой вопрос любой задачи на два указателя — **почему можно выбросить элемент, не проверив с ним все пары**. Ответ всегда один и тот же по форме: «этот элемент в паре с самым выгодным из оставшихся дал недостаточно хороший результат, значит с остальными будет только хуже».

Если для твоей задачи такое рассуждение не строится — два указателя не подойдут, сколько ни двигай.

<Note tone="trap" title="Самая частая ошибка">
  Условие цикла. `left <= right` вместо `left < right` позволяет указателям встать на один элемент и
  сложить его сам с собой. На большинстве тестов это незаметно, а на входе из одного элемента даёт
  неверный ответ.
</Note>

## Что в теме

Четыре разбора, от простого к неприятному:

1. **Пара с заданной суммой** — базовая схема навстречу, инвариант в чистом виде.
2. **Квадраты отсортированного массива** — заполнение результата с конца и почему `unshift` всё портит.
3. **Проверка на палиндром** — очистка строки регуляркой и выход на первом же несовпадении.
4. **Три числа с нулевой суммой** — два указателя внутри перебора и три места, где нужно пропускать дубликаты.
