Граф — вершины и рёбра между ними. В отличие от дерева, циклы разрешены, а «корня» может не быть вовсе. Социальные связи, маршруты, зависимости модулей, состояния конечного автомата — всё это графы.

## Главный навык темы — увидеть граф

Половина задач не содержит слова «граф». Их надо распознать:

- **Сетка** — ячейка вершина, соседство по стороне ребро. Острова, лабиринты, заражение.
- **Зависимости** — «А требует B». Порядок сборки, пререквизиты курсов.
- **Состояния** — «из слова X одной заменой буквы получается Y». Word ladder.
- **Отношения** — друзья, подписки, транзакции.

Как только увидел граф, дальше — стандартный набор: DFS, BFS, топологическая сортировка, поиск циклов.

## Представление

```js
// Список смежности — почти всегда лучший выбор
const graph = { a: ['b', 'c'], b: ['d'], c: ['d'], d: [] };
```

Память O(V + E), обход соседей за O(степени). Матрица смежности (V×V) занимает O(V²) даже для разреженного графа — оправдана только когда рёбер почти столько же, сколько пар вершин.

**Для сетки список смежности строить не нужно** — соседи считаются арифметикой: `[r±1, c]`, `[r, c±1]`.

## DFS против BFS

| | DFS | BFS |
|---|---|---|
| Структура | стек (или рекурсия) | очередь |
| Память | O(глубины) | O(ширины) |
| Кратчайший путь | ✗ | ✓ (без весов) |
| Заливка компоненты | ✓ | ✓ |
| Обнаружение цикла | ✓ проще | сложнее |

Правило: **нужен кратчайший путь — BFS. Нужно просто всё обойти — DFS** (он короче и памяти обычно меньше).

## visited — не опция

Без множества посещённых обход по графу с циклом **не завершится**. И отмечать посещение нужно **в момент добавления в очередь/стек**, а не при обработке — иначе одна вершина попадёт в очередь несколько раз.

```js
// ✅ правильно
if (!visited.has(next)) {
  visited.add(next);       // ← здесь
  queue.push(next);
}
```

## Стандартный набор задач

- **Компоненты связности** — «сколько групп». Обход из каждой непосещённой вершины, счётчик.
- **Кратчайший путь без весов** — BFS.
- **Кратчайший путь с весами** — Дейкстра (BFS + куча).
- **Порядок с зависимостями** — топологическая сортировка.
- **Есть ли цикл** — DFS с тремя цветами или алгоритм Кана.

## Что в теме

1. **Количество островов** — компоненты связности и сетка как граф.
2. **Топологическая сортировка** — зависимости и обнаружение циклов.
