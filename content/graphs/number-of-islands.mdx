## Задача

В сетке `'1'` — суша, `'0'` — вода. Остров — группа клеток суши, связанных по стороне (не по диагонали). Сколько островов?

## Инсайт: сетка — это граф

Строить список смежности не нужно. Вершина — ячейка, соседи — `[r-1,c]`, `[r+1,c]`, `[r,c-1]`, `[r,c+1]`. Всё остальное — стандартный обход графа.

Схема подсчёта компонент связности универсальна:

```js
for (каждая вершина) {
  if (это суша && не посещена) {
    counter += 1;
    залить всю компоненту обходом;
  }
}
```

Заливка помечает **всю** компоненту, поэтому второй раз мы в неё не попадём — и каждая компонента посчитается ровно один раз.

## DFS или BFS — без разницы

Компоненту нужно просто «накрыть» целиком, порядок обхода не важен. Здесь DFS через явный стек: рекурсия на сетке 1000×1000 из сплошной суши даст глубину миллион и переполнение стека.

Каждая заливка красит одну компоненту. Счётчик увеличивается только когда встречается **непосещённая** суша.

## Сложность

**Время — O(rows · cols).** Каждая ячейка проверяется во внешнем цикле один раз и обрабатывается заливкой максимум один раз.

**Память — O(rows · cols)** на `visited` и стек в худшем случае (вся сетка — один остров).

## Экономия памяти: топить сушу

Вместо `visited` можно **менять сетку**: посещённую сушу переписывать в `'0'`. Тогда `visited` не нужен вовсе — память O(размера стека).

```js
grid[r][c] = '0';  // «затопили» — второй раз не зайдём
```

Приём стандартный, но **мутирует вход**. Если вызывающему сетка ещё нужна — это баг. В разборе поэтому копия и явный `visited`.

## Ловушки

- **Диагональ.** Условие обычно про соседство по стороне — 4 направления, не 8. Прочитай внимательно.
- **Отметка при обработке вместо добавления.** Ячейка попадёт в стек несколько раз: работа лишняя, а при большой сетке стек раздувается.
- **Пустая сетка.** `grid[0]?.length` — иначе `undefined.length` упадёт.
- **Мутация входа без предупреждения.** Если топишь сушу — задокументируй или работай с копией.

## Обобщение

Тот же код решает: «сколько групп друзей», «сколько связных областей одного цвета», «сколько кластеров». Меняется только определение соседства.
