## Задача

Найти **первый** индекс `i`, начиная с которого выполняется условие `nums[i] >= target`. Если такого нет — вернуть длину массива (позицию вставки).

Это `lower_bound` из C++ и `bisect_left` из Python — один из самых часто используемых примитивов.

## Инсайт: ищем границу, а не элемент

Забудь про «среднее значение». Мы ищем **границу в массиве булевых значений**:

```
индекс:   0  1  2  3  4  5
значение: 1  3  5  6  8  9
nums[i]>=5: F  F  T  T  T  T
                ^ граница
```

Условие монотонно: стало истинным — таким и останется. Значит бинарный поиск найдёт границу.

## Один шаблон вместо трёх веток

```js
let left = 0;
let right = nums.length;   // за массивом: ответ «такого нет»
while (left < right) {
  const mid = left + ((right - left) >> 1);
  if (nums[mid] >= target) right = mid;  // mid может быть ответом
  else left = mid + 1;                   // mid точно не ответ
}
return left;
```

Две ветки вместо трёх, и **невозможно зациклиться**: `right = mid` (а не `mid - 1`) гарантирует, что кандидат не теряется, а `left = mid + 1` — что отрезок строго сокращается.

## Почему `right` начинается с длины, а не с `length - 1`

Потому что ответ «условие нигде не истинно» должен быть **выразим**. Если все элементы меньше target, граница — это длина массива: туда и нужно вставить в конец. Стартуя `right = length`, мы оставляем для этого случая место.

То же для случая «условие истинно везде» — граница на нуле, и это обрабатывается естественно.

## Сложность

**Время — O(log n).** Память — O(1).

## Ловушки

- **Строгое `<` в `while`.** `right` — это граница, а не индекс элемента. Равно даёт `right === left`, и цикл зацикливается на одном элементе.
- **`right = mid`, а не `mid - 1`.** mid может оказаться ответом, выбрасывать его нельзя.
- **Несовместимые типы `while` и `right`.** Точная форма (`right = n - 1`, `<=`) и форма границы (`right = n`, `<`) — две разные вселенные. Смешать элементы из них — верный баг.

## Бинарный поиск по ответу

Самое ценное применение формы границы. Когда условие проверяется не по индексу массива, а по **значению ответа**, отдельного массива не нужно:

- «Минимальная скорость поедания, при которой успеваем за h часов» — если скорость X подходит, подойдёт и X+1. Монотонно. Бинпоиск по скорости.
- «Минимальная вместимость корабля, при которой груз увозится за d дней» — бинпоиск по вместимости.

Шаблон тот же, только `predicate(mid)` проверяет условие задачи для значения `mid`, а не `nums[mid]`.
