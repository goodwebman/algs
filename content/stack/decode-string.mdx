## Задача

Раскодировать строку вида `3[a2[c]]` → `accaccacc`. Поддерживается произвольная вложенность и многозначные множители.

## Инсайт: произвольная вложенность → стек

Когда глубина вложенности **фиксирована**, хватит переменных. Когда она **произвольна** — это всегда сигнал «нужен стек или рекурсия». Стек хранит отложенный контекст каждого незакрытого уровня.

На каждом уровне накапливается два значения:
- `text` — что уже собрано внутри этого блока;
- `count` — множитель, который применится при закрытии блока.

## Схема

```
3 [ a 2 [ c ] ]
        ^     ^
        откр  закр
```

На `[` — откладываем текущий накопленный текст и множитель на стек, начинаем новый пустой уровень. На `]` — достаём отложенное, склеиваем: `снаружи + внутренность × множитель`.

```js
if (char === '[') {
  stack.push({ text: current, count });
  current = '';
  count = 0;
} else if (char === ']') {
  const frame = stack.pop();
  current = frame.text + current.repeat(frame.count);
}
```

## Многозначный множитель

`12[a]` — это `count = 12`, а не две отдельные цифры. Накапливаем:

```js
if (char >= '0' && char <= '9') {
  count = count * 10 + Number(char);
}
```

Сдвиг влево (`* 10`) и прибавление цифры — стандартный разбор чисел из потока символов.

## Как это выглядит по шагам

<Viz algo="decode-string" />

Стек отложенных уровней растёт на каждой `[` и схлопывается на `]`. На пресете `3[a2[c]]` хорошо видна вложенность: внутренний блок `2[c]` собирается первым, потом возвращается на уровень `3[...]`.

## Сложность

**Время — O(длины результата).** Каждая буква копируется столько раз, во сколько блоков она вложена. Результат `100[a]` — это 100 копий одной буквы, и это честная работа.

**Память — O(глубины вложенности)** на стек плюс O(длины результата) на сборку строки.

## Ловушки

- **Односимвольный разбор чисел.** `count = Number(char)` перезаписывает, и `12` превращается в `2`. Накапливай через `* 10`.
- **`current` не сбрасывается на `[`.** Открывая блок, мы начинаем собирать заново; внешний текст уже отложен на стеке.
- **Хвост без кодирования.** Строка `abc3[d]ef` — буквы до и после блока должны попасть в ответ. Цикл обрабатывает все символы, так что это работает само.

## JS-специфика: `String.repeat`

`'ab'.repeat(3)` → `'ababab'`. Дешевле, чем цикл конкатенации (который формально O(n²) из-за иммутабельности строк, хотя V8 оптимизирует через ropes). Для длинных повторений — заметно.
