Отдельный трек: задачи не на алгоритмы, а **на сам язык**. Их дают на собеседованиях, чтобы проверить понимание замыканий, промисов, event loop и особенностей сравнения — тех мест, где JS ведёт себя не так, как ожидается.

Алгоритмической сложности здесь почти нет. Сложность — в деталях языка.

## Что здесь проверяется

**Замыкания и каррирование.** Функция, возвращающая функцию, — база для декораторов, мемоизации, частичного применения. Задача про калькулятор выглядит игрушечной, но именно она показывает, понимаешь ли ты, что «функция» и «значение» в JS — одно и то же.

**Промисы и event loop.** `Promise.race`, порядок `resolve`/`reject`, очистка таймеров, `await` внутри `try`. Ошибки здесь тихие: код работает на счастливом пути и молча ломается на ошибочном.

**Сравнение значений.** `NaN !== NaN`, `+0 === -0`, `[] == false`. Глубокое сравнение — задача, где эти углы вылезают все разом.

**Подписки и утечки.** EventEmitter — про то, как хранить колбэки и корректно отписываться. Отписка «во время рассылки» ломает наивную реализацию.

## Типичные ошибки, которые тут ловятся

```js
// ❌ filter без колбэка — ReferenceError при каждом вызове
list.filter(cb !== callback);

// ❌ первый аргумент исполнителя — resolve, а не reject
new Promise((reject) => setTimeout(() => reject('timeout'), ms));

// ❌ без await ошибка пролетит мимо catch
try { return fn(); } catch { /* сюда не попадём */ }

// ❌ JSON.stringify как «глубокое сравнение»
JSON.stringify(a) === JSON.stringify(b);
```

Каждая из них — реальный баг из старой версии этого репозитория. В задачах ниже они закрыты тестами.

## Как решать

Формат тот же: пиши в песочнице, гоняй тесты. Отличие — большинство задач требует не одну функцию, а конструкцию (класс, обёртку, набор функций). Поэтому у некоторых есть «драйвер» — функция, через которую тесты дёргают твою реализацию. Её тело менять не нужно, только заполнить то, что выше.

## Задачи трека

1. **EventEmitter** — on/off/emit и подписка, отписывающаяся во время рассылки.
2. **Промис с таймаутом** — `Promise.race`, порядок resolve/reject, очистка таймера.
3. **Retry с backoff** — повторы, паузы, проброс последней ошибки.
4. **Глубокое сравнение** — `NaN`, `±0`, прототипы, циклические ссылки.
5. **Run-Length Encoding** — простая на вид, но с классической потерей последней серии.
6. **Функциональный калькулятор** — замыкания и каррирование в чистом виде.
