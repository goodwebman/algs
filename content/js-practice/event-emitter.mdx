## Задача

Реализовать `EventEmitter`: `on(event, cb)` подписывает, `off(event, cb)` отписывает конкретный колбэк, `emit(event, ...args)` вызывает всех подписчиков.

## Три подводных камня

**1. Отписка конкретного колбэка.**

```js
// ❌ ReferenceError: cb не определён — это выражение, а не колбэк
list.filter(cb !== callback);

// ✅
list.filter((cb) => cb !== callback);
```

Опечатка на одну стрелку, и `off` падает при каждом вызове. Именно эта ошибка жила в исходной версии из старого репозитория.

**2. Отписка во время рассылки.** Подписчик может вызвать `off` прямо в обработчике:

```js
emitter.on('tick', function handler() {
  emitter.off('tick', handler);   // отписывается на первом же событии
});
```

Если `emit` обходит массив напрямую, мы мутируем его во время итерации — часть подписчиков будет пропущена. Решение: обходить **копию**.

```js
for (const callback of [...list]) callback(...args);
```

**3. Утечки.** Пустой массив после отписки лучше удалять из `Map`, иначе на долгоживущем эмиттере накапливаются ключи с пустыми списками.

## Хранилище

`Map<событие, массив колбэков>`. Массив, а не `Set`: порядок подписки обычно важен — подписчики вызываются в порядке `on`.

## Сложность

- `on` — O(1);
- `emit` — O(количества подписчиков);
- `off` — O(количества подписчиков) из-за `filter`.

Если отписка происходит часто и подписчиков тысячи, `off` за O(n) становится проблемой — тогда `Set` (O(1) на удаление) ценой потери порядка.
