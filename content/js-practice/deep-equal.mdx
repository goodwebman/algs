## Задача

`deepEqual(a, b)` — глубокое сравнение произвольных значений.

## Почему не `JSON.stringify`

```js
JSON.stringify(a) === JSON.stringify(b);
```

Однострочник, который ломается сразу в нескольких местах:

- **Порядок ключей.** `{a:1,b:2}` и `{b:2,a:1}` дадут разные строки, хотя объекты равны.
- **`undefined` теряется.** `{a: undefined}` сериализуется в `{}`.
- **`NaN` превращается в `null`.** Два `NaN` сравняются, но по неправильной причине — а `NaN` и `null` тоже.
- **Циклы роняют.** `TypeError: Converting circular structure to JSON`.
- **`Date` становится строкой**, `Map`/`Set` — пустым объектом, `BigInt` бросает исключение.

## Начни с `Object.is`

```js
if (Object.is(a, b)) return true;
```

Одна строка закрывает два неочевидных случая:

- **`NaN` равен `NaN`** — в отличие от `===`. Без этого тест «среднее пустого массива» никогда не пройдёт.
- **`+0` не равен `−0`** — в отличие от `===`. Формально это разные значения, и для сравнения структур различие обычно значимо.

## Прототип как проверка типа

```js
if (Object.getPrototypeOf(a) !== Object.getPrototypeOf(b)) return false;
```

Отсекает разом: массив против объекта, `Date` против обычного объекта, экземпляры разных классов. Одна строка вместо цепочки `Array.isArray`, `instanceof`, `typeof`.

## Циклические ссылки

```js
if (seen.get(a) === b) return true;
seen.set(a, b);
```

`WeakMap` пар «уже сравниваем». Встретили ту же пару повторно — значит зашли в цикл; считаем совпавшей и возвращаемся, иначе бесконечная рекурсия.

`WeakMap`, а не `Map`, чтобы не удерживать объекты от сборки мусора.

## Что ещё стоит поддержать

| Тип | Как сравнивать |
|---|---|
| `Date` | `getTime()` |
| `RegExp` | `source` и `flags` |
| `Map` | размер + каждая пара ключ-значение |
| `Set` | размер + вхождение каждого элемента |
| `TypedArray` | длина + побайтово |

Для `Set` объектов сравнение сложнее: `set.has(obj)` работает по ссылке, поэтому нужен перебор с `deepEqual` — O(n²) на множество.

## Сложность

**Время — O(размера структуры)** при простых значениях; O(n²) на `Set`/`Map` с объектными ключами.

**Память — O(глубины)** на стек рекурсии плюс `WeakMap`.
