## Задача

Классика на замыкания. Нужно, чтобы работало:

```js
seven(plus(five()))   // 12
four(minus(nine()))   // -5
```

## Как это вообще возможно

Ключ в том, что **число здесь — это функция**, а не значение:

```js
const makeNumber = (value) => (operation) => (operation ? operation(value) : value);
```

Вызов без аргумента (`five()`) возвращает само число. Вызов с операцией (`five(plus(3))`) применяет операцию к числу.

## Каррирование операции

```js
const plus = (b) => (a) => a + b;
```

`plus(5)` не складывает — он возвращает **функцию**, ожидающую второй операнд. Разберём `seven(plus(five()))` изнутри:

1. `five()` → `5`;
2. `plus(5)` → функция `(a) => a + 5`;
3. `seven(эта функция)` → применяет её к `7` → `7 + 5 = 12`.

## Порядок операндов — главная ловушка

Для `plus` порядок неважен (сложение коммутативно), а для `minus` — критичен:

```js
four(minus(nine()))   // должно быть 4 - 9 = -5, а не 9 - 4 = 5
```

Внутренний аргумент (`nine`) приходит **первым** по времени, но становится **правым** операндом. Внешнее число (`four`) — левый операнд.

```js
const minus = (b) => (a) => a - b;
//             ^право   ^лево
```

Перепутать — и знак результата инвертируется на всех несимметричных операциях. Тест `four minus nine` в задаче стоит именно для этого.

## Зачем это в реальном коде

Каррирование — не трюк для собеседований. Оно даёт **частичное применение**:

```js
const log = (level) => (message) => console.log(`[${level}] ${message}`);
const error = log('error');   // готовый логгер уровня error
```

Отсюда растут middleware в Express и Redux, декораторы, `pipe`/`compose` в функциональных библиотеках. Идея одна: функция, возвращающая функцию с «зашитым» контекстом.

## Замыкание держит значение

`plus(5)` возвращает функцию, которая **помнит** `b = 5` после того, как `plus` завершился. Это и есть замыкание: внутренняя функция сохраняет доступ к области видимости внешней.

Практическое следствие — такие функции удерживают в памяти всё, на что ссылаются. Замыкание над большим массивом не даст сборщику мусора его собрать, пока живёт сама функция.
