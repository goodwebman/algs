## Задача

Проверить, является ли бинарное дерево деревом поиска: **всё** левое поддерево меньше узла, **всё** правое больше.

## Неправильное решение, которое пишут почти все

```js
// ❌ НЕВЕРНО
const isBst = (node) =>
  !node ||
  ((!node.left || node.left.value < node.value) &&
   (!node.right || node.right.value > node.value) &&
   isBst(node.left) && isBst(node.right));
```

Проверка **локальна**: сравнивает узел только с непосредственными детьми. А свойство BST **глобально**.

Контрпример:

```
      5
    /   \
   1     6
        / \
       3   7
```

Здесь `3 < 6` (левый ребёнок меньше родителя ✓) и `6 > 5` (правый ребёнок больше корня ✓). Локальная проверка проходит. Но `3` лежит в **правом поддереве корня 5** и обязана быть больше 5. Это не BST.

## Правильно: передавать диапазон вниз

Каждый узел обязан лежать в интервале, который сужается по мере спуска:

```js
const check = (node, min, max) => {
  if (!node) return true;
  if (node.value <= min || node.value >= max) return false;

  return check(node.left, min, node.value)    // влево: сужаем верх
      && check(node.right, node.value, max);  // вправо: сужаем низ
};

check(root, -Infinity, Infinity);
```

Уходя влево, узел становится **верхней** границей для всего поддерева. Уходя вправо — **нижней**. Так глобальное свойство проверяется локально, но с накопленным контекстом.

## Сложность

**Время — O(n).** Каждый узел проверяется один раз.

**Память — O(h)** на стек рекурсии.

## Ловушки

- **Нестрогие неравенства.** В классическом BST дубликаты не допускаются: `<=` и `>=`. Если условие задачи разрешает дубликаты слева — сравнение слева станет `<`, а справа останется `>=`. Это решение задачи, а не деталь реализации.
- **`Infinity` как границы.** Работает, пока значения — обычные числа. Если в дереве могут быть `Infinity`, нужны `null`-границы с явной проверкой.
- **In-order вместо диапазонов.** Альтернатива: обойти дерево in-order и проверить, что результат строго возрастает. Тоже верно и иногда проще. Но требует хранить предыдущее значение и не даёт раннего выхода без дополнительной логики.

## Альтернатива через in-order

```js
let prev = -Infinity;
let ok = true;

const inorder = (node) => {
  if (!node || !ok) return;
  inorder(node.left);
  if (node.value <= prev) ok = false;
  prev = node.value;
  inorder(node.right);
};
```

Опирается ровно на то свойство из [обходов](/t/trees/tree-traversals): in-order на BST даёт отсортированный порядок. Если порядок не возрастает — это не BST.
