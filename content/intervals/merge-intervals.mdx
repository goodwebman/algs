## Задача

Дан массив интервалов. Слить все пересекающиеся и вернуть массив непересекающихся.

`[[1,3],[2,6],[8,10],[15,18]]` → `[[1,6],[8,10],[15,18]]`.

## Инсайт: сортировка делает задачу линейной

Без сортировки нужно сравнивать каждый интервал с каждым — O(n²), и после слияния двух возможны новые пересечения, которые надо искать заново.

После сортировки по началу достаточно **сравнивать только с последним интервалом в результате**. Все предыдущие начинаются раньше и уже обработаны — новый интервал не может пересечься с ними, не пересекаясь с последним.

```js
const sorted = [...input].sort((a, b) => a[0] - b[0]);

for (const [start, end] of sorted) {
  const last = merged.at(-1);

  if (last && start <= last[1]) {
    last[1] = Math.max(last[1], end);   // расширяем
  } else {
    merged.push([start, end]);           // новый интервал
  }
}
```

## Math.max — не украшение

```js
merged[merged.length - 1] = [last[0], Math.max(last[1], end)];
```

Без `Math.max` вложенный интервал сломает результат: `[[1,10],[2,3]]` дал бы `[1,3]` вместо `[1,10]`. Конец сливаемого интервала может быть **меньше** текущего конца — сортировка по началу этого не исключает.

## Сложность

**Время — O(n log n)**, доминирует сортировка. Сам проход линейный.

**Память — O(n)** на копию и результат. Если вход разрешено мутировать, можно сортировать на месте — тогда O(log n) на стек сортировки плюс результат.

## Ловушки

- **Мутация входа.** `input.sort()` переставит элементы в массиве вызывающего. Копия обязательна, если не оговорено обратное.
- **Компаратор в `sort`.** Без него `[[10,20],[9,15]]` сравнится как строки `"10,20"` и `"9,15"` — и `"9"` окажется больше. Классика.
- **Касание.** `start <= last[1]` сливает `[1,4]` и `[4,5]` в `[1,5]`. Если по условию касание не считается пересечением — строгое `<`.
- **Пустой массив.** `merged.at(-1)` вернёт `undefined` — проверка `last &&` обязательна.

## Обобщение: те же две строки

Изменив условие и действие, тот же скелет решает соседние задачи:

- **Вставить интервал в отсортированный список** — тот же проход, но вход уже отсортирован.
- **Пересечение двух списков интервалов** — два указателя по спискам.
- **Свободные окна в расписании** — слить занятые, вернуть промежутки между ними.
