Задачи про отрезки времени: брони переговорок, расписания, периоды доступности, наложение подписок. Тема маленькая, потому что почти всё сводится к одному приёму.

## Приём: сначала сортировка

**Отсортируй интервалы — и задача становится линейной.** Без сортировки нужно сравнивать каждый с каждым: O(n²).

По чему сортировать — зависит от задачи, и это единственное решение, которое надо принять:

| Задача | Сортировать по |
|---|---|
| Слить пересекающиеся | **началу** |
| Максимум непересекающихся (выбор заявок) | **концу** |
| Минимум комнат для всех встреч | началу + куча концов |

Сортировка по концу в задаче о заявках — жадный алгоритм, и он доказуемо оптимален: беря заявку, которая заканчивается раньше, мы оставляем максимум места для остальных.

## Условие пересечения

Два интервала `[a1, a2]` и `[b1, b2]` пересекаются, если:

```js
a1 <= b2 && b1 <= a2
```

После сортировки по началу (`a1 <= b1`) условие упрощается до `b1 <= a2`.

<Note tone="trap" title="Касание — это пересечение?">
  `[1,3]` и `[3,5]` — пересекаются или нет? Зависит от задачи. Для брони переговорки — нет
  (одна кончилась, другая началась). Для слияния отрезков — обычно да. Разница в одном символе:
  `<=` против `<`. Уточняй у интервьюера или фиксируй в комментарии.
</Note>

## Второй приём: события

Задачи вида «сколько встреч идёт одновременно в пике» решаются превращением интервалов в **события**:

```js
// [1,5] → { time: 1, delta: +1 }, { time: 5, delta: -1 }
```

Сортируем все события по времени, идём и накапливаем счётчик. Максимум счётчика — ответ.

Приём работает для «максимальное перекрытие», «минимум ресурсов», «интервалы покрытия» — везде, где важно не само наложение, а его количество.

## Ловушки темы

- **Мутация входа.** `intervals.sort()` сортирует исходный массив вызывающего. `[...intervals].sort()`.
- **Компаратор.** `sort()` без него сравнивает как строки: `[[10,20],[9,15]]` отсортируется неверно.
- **Вложенные интервалы.** `[1,10]` и `[2,3]` — при слиянии конец не должен «укоротиться» до 3. Нужен `Math.max`.
- **Пустой вход.** Обработать до цикла.

## Что в теме

1. **Слияние интервалов** — базовый приём: сортировка по началу и один проход.
