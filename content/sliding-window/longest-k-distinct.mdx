## Задача

Найти длину самой длинной подстроки, содержащей **не более k различных** символов.

`"eceba"`, k=2 → 3 (подстрока `"ece"`).

## Инсайт: состояние окна — это Map

В предыдущих задачах состоянием окна было одно число: сумма, количество нулей. Здесь условие про **состав**, поэтому состояние — счётчик частот:

```js
freq.set(str[right], (freq.get(str[right]) ?? 0) + 1);
```

Количество различных символов — это `freq.size`. Условие допустимости — `freq.size <= k`.

## Ключевая деталь: удаляй ключ на нуле

При сжатии окна недостаточно уменьшить счётчик — нужно **удалить запись**, когда счётчик дошёл до нуля:

```js
freq.set(str[left], freq.get(str[left]) - 1);
if (freq.get(str[left]) === 0) freq.delete(str[left]);
```

Если оставить запись со значением 0, `freq.size` будет считать символы, которых в окне уже нет. Условие `freq.size > k` останется истинным навсегда, `left` доедет до конца массива, и алгоритм вернёт мусор.

<Note tone="trap" title="Почему это ловится не сразу">
  На входах, где каждый символ встречается один раз, счётчик сразу падает до нуля и запись
  удаляется — баг не проявляется. Он вылезает только когда символ повторяется в окне. Проверяй на
  `"aabbcc"`, а не на `"abcdef"`.
</Note>

## Сложность

**Время — O(n).** Каждый символ входит в окно один раз и выходит один раз, операции с `Map` — O(1).

**Память — O(k).** В `Map` одновременно не больше k+1 записей: как только становится k+1, окно сжимается.

Это важно: память зависит от k, а не от длины строки. Даже на строке в мегабайт при k=3 в памяти будет четыре записи.

## Ловушки

- **`k = 0`.** Окно не может содержать ни одного символа, ответ 0. Без явной проверки цикл сжатия отработает корректно и вернёт 0 сам — но убедись, что не делишь где-нибудь на k.
- **Объект вместо `Map`.** `Object.keys(o).length` — это O(n) на каждой итерации, что превращает алгоритм в O(n²). `map.size` — O(1).
- **Строка с эмодзи.** `input[i]` режет по code units. Обходи через `[...input]`.

## Вариант «ровно k различных»

Частая модификация. Прямого решения окном у неё нет — монотонность ломается. Стандартный приём:

```
ровно(k) = не более(k) − не более(k − 1)
```

Два запуска той же функции. Приём общий: «ровно» почти всегда выражается через разность двух «не более».
