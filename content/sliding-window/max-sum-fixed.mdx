## Задача

Найти максимальную сумму `k` подряд идущих элементов массива.

## Наивное решение

```js
// ❌ O(n·k)
let best = -Infinity;
for (let i = 0; i + k <= nums.length; i += 1) {
  let sum = 0;
  for (let j = i; j < i + k; j += 1) sum += nums[j];
  best = Math.max(best, sum);
}
```

Работает. Но обрати внимание, что происходит между итерациями: окно `[i…i+k-1]` и окно `[i+1…i+k]` отличаются **ровно двумя элементами**, а мы честно складываем все `k` заново.

## Инсайт: пересчёт вместо перерасчёта

```js
windowSum += nums[right];
if (right - left + 1 === k) {
  maxSum = Math.max(maxSum, windowSum);
  windowSum -= nums[left];
  left += 1;
}
```

Две строки вместо внутреннего цикла. Вошло значение справа, вышло слева — сумма обновлена за две операции вместо `k`. Окно само дорастает до `k` на первых итерациях, отдельная сборка первого окна не нужна.

Это общая идея всей темы: **храни состояние окна и обновляй его инкрементально**. Здесь состояние — одно число, дальше в теме это будут счётчики и хеш-таблицы, но принцип не меняется.

Счётчик «чтений» под визуализацией показывает цену буквально: одно чтение на вход элемента и ещё одно на выход — по два на позицию вместо `k`.

## Сложность

**Время — O(n).** Каждый элемент ровно один раз входит в окно и один раз выходит.

**Память — O(1).** Одна переменная суммы.

## Ловушки

- **`k > nums.length`.** Окна не существует. Вернуть 0, `-Infinity` или бросить ошибку — решение за тобой, но обработать нужно явно. То же с `k = 0`: без явного guard'а наружу уйдёт `-Infinity`.
- **Инициализация `maxSum = 0`.** На массиве из одних отрицательных это даст неверный ответ 0. Начинай с `-Infinity`.
- **Накопление ошибки на дробных числах.** Инкрементальный пересчёт складывает и вычитает одни и те же значения много раз, и для `float` погрешность накапливается. На целых числах проблемы нет; на деньгах считай в копейках целыми.

## JS-специфика

`Math.max(...arr)` на большом массиве бросит `RangeError: Maximum call stack size exceeded` — спред раскладывает массив в аргументы, а их количество ограничено (порядка 100 000 в V8). В цикле сравнивай через обычный `if` или `reduce`.
